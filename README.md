# 📊 Olist电商用户行为分析项目

基于巴西 Olist 电商平台 10万+订单数据，围绕用户转化路径、用户价值分层及品类销售表现展开分析，为用户运营与品类策略优化提供数据支持。

## 项目背景

随着电商平台用户规模扩大，如何识别高价值用户、降低用户流失率并优化品类运营成为重要课题。

本项目基于 Olist 电商平台公开订单数据，通过数据分析挖掘用户行为特征，为运营决策提供依据。

---

## 数据概况

数据来源：

Brazilian E-Commerce Public Dataset by Olist

数据规模：

* 10万+订单记录
* 2016-2018年电商交易数据
* 用户、订单、商品、支付等多个维度

核心数据表：

* olist_orders_dataset
* olist_order_items_dataset
* olist_customers_dataset
* olist_products_dataset

## 分析流程

### 1. 数据清洗与整合

* 处理缺失值与异常值
* 统一时间格式
* 多表关联构建分析宽表

### 2. 用户转化路径分析

分析订单状态变化过程，评估平台履约与订单流失情况。

主要发现：

* 平台整体订单流失率较低
* 用户取消订单比例较小
* 履约流程较稳定

### 3. RFM用户价值分层

基于最近消费时间（Recency）、消费频率（Frequency）及消费金额（Monetary）构建RFM模型，并结合KMeans聚类进行用户分群。

用户结构：

* 低频低价值用户：54.2%
* 高流失低价值用户：40.1%
* 中高频中等价值用户：3.1%
* 高价值单次消费用户：2.6%

### 4. 品类销售分析

热门品类：

* beleza_saude（美容健康）
* relogios_presentes（钟表礼品）
* cama_mesa_banho（床品卫浴）

* 高价值用户：会员权益与专属服务

* 加大热门品类曝光资源

* 结合季节性需求开展促销活动
